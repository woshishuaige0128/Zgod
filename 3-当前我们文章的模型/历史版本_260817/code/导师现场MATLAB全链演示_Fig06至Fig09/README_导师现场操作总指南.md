# 小论文 Fig.6--Fig.9 导师现场 MATLAB 全计算链操作总指南

## 先说结论

导师现场不要打开原来四个图文件夹中的 `RUN_THIS_FIGURE.m` 来证明完整计算，因为那些文件从既有40961×10 CSV开始，只完成绘图。

本文件夹新增的四个 `RUN_FIGxx_FULLCHAIN.m` 才是现场入口。它们从15自由度结构参数和矩阵开始，重新计算Guyan与Craig--Bampton模型、生成激励、运行Simulink、恢复三层物理响应、绘图，最后才读取当前CSV进行验收。

科学证据等级是：**计算级复现（现存代码/必要适配路线）**。它不是作者原始SLX保存状态直接运行，也不是梁禹当年工作区历史数组已经找回。

## MATLAB图形界面逐步操作

1. 启动 MATLAB R2025b。需要 Simulink 和 Control System Toolbox。
2. 在MATLAB左侧“当前文件夹”地址栏粘贴本文件夹的绝对路径并回车。
3. 双击要汇报的图文件夹，再双击对应 `RUN_FIGxx_FULLCHAIN.m`。
4. 快速演示：点击编辑器上方绿色“运行”，或按 `F5`。
5. 逐段讲解：先将光标放在最上方第1--62行的“现场全计算链演示入口”初始化节，点击“运行节”或按 `Ctrl+Enter`；再按第1节到第9节顺序执行。不能直接从第63行开始，否则本图路径、配置和输出目录尚未建立。
6. 运行期间保留命令窗口。成功时必须依次看到 `[1/9]` 到 `[9/9]`，最后看到：

   ```text
   STATUS=PASS
   FULL_CHAIN=PASS
   ```

7. 结果图会在桌面MATLAB中直接显示，同时保存到本图文件夹的 `输出/本轮计算图/`。
8. 运行后可在命令窗口输入以下命令展示关键证据：


## 九个代码章节在做什么

在九个计算章节之前，第1--62行是入口初始化节：它根据当前脚本文件名识别具体图号，建立全部本地路径和输出目录，把Simulink缓存限制在本图输出文件夹，并启动日志。使用 `F5` 时会自动执行；使用 `Ctrl+Enter` 逐节演示时必须先运行这一节。

1. **建立15自由度原结构**：运行 `PDmonicanshu.m`，依据梁柱几何、钢材参数和单元刚度重新装配质量矩阵 `M_full`、阻尼矩阵 `C_full`、刚度矩阵 `K_full`。
2. **准备运行模型副本**：复制原始SLX，在副本中接入本轮工作区激励并改成本地地震文件路径；第二类划分补齐三层Guyan和Craig--Bampton输出。
3. **重新进行结构缩聚**：按主/从自由度重排矩阵，计算Guyan静力变换 `T_guyan`；计算固定界面模态并保留前3阶，形成 `T_cb`。
4. **建立状态空间和楼层恢复**：把三套二阶动力方程转为一阶状态空间，并让降阶坐标恢复成一、二、三层实际水平位移。
5. **现场生成激励**：Fig.6/7读取原始El Centro记录并乘0.40；Fig.8/9直接按公式生成0.1--10 Hz线性Chirp。
6. **Simulink积分**：使用 `ode4`、固定步长1/1024 s运行40 s。三个模型并行计算Original、Guyan和Craig--Bampton。
7. **恢复并保存物理响应**：形成 `response_mm(时间,楼层,方法)`，尺寸40961×3×3，并保存本轮新算CSV/MAT。
8. **直接用新算响应绘图**：绘制一层和三层的全时程及两个局部窗，导出矢量PDF和600 dpi PNG。
9. **末端验收**：到这一步才读取“参考结果_仅用于末端验收”中的当前CSV，逐点比较新算结果；门槛为最大绝对差不超过1e-12 mm。

## 现场必须主动说明的两件事

### 1. Guyan公式边界

本演示为了追踪梁禹现存计算路线，保留其单侧缩聚：

```matlab
T  = [eye(nm); -Kss\Ksm];
Mg = Mmm - Mms*(Kss\Ksm);
Cg = Cmm - Cms*(Kss\Ksm);
Kg = Kmm - Kms*(Kss\Ksm);
```

这与小论文理论部分采用的双侧合同投影 `T'*M*T`、`T'*C*T`、`T'*K*T` 不完全相同。因此现场应说“我正在复现现存代码怎样算出这些结果”，不能说“这证明两套理论公式完全一致”。

### 2. Fig.9与硕士论文图3-15的差别

硕士论文图3-15的0--40 s主图来自第二类划分Chirp三层响应，但两个局部窗历史上混入了El Centro三层响应的10--11 s和21.5--22.5 s。当前小论文Fig.9使用物理一致版本：全时程和局部窗都来自同一次Chirp计算，局部窗为13--14 s和38--38.3 s。

所以Fig.9不应与硕士论文历史组合版完全一样；这是修正数据源混用，不是计算失败。

## 正常警告与真正失败

运行时可能看到 `Chirp Signal2`、`Step1` 或第二类模型 `Demux2` 未连接的黄色警告。这些是原SLX中已被本轮 `From Workspace` 输入旁路的遗留块，日志保留它们以便审计。

判断方法：

- 黄色警告后仍继续出现 `[6/9]` 到 `[9/9]`，最后为 `FULL_CHAIN=PASS`：正常。
- 出现红色错误、没有生成40961×3×3响应、或没有 `FULL_CHAIN=PASS`：本次运行失败，不能继续汇报为成功。
