# Fig. 10 双时滞稳定域：MATLAB操作说明

## 一句话说明

这个文件夹已经带齐代码和六份输入数据。把整个 `Fig10_双时滞稳定域` 文件夹单独复制到任意位置，仍然可以运行。

## 第一次画图：一步一步操作

1. 启动 MATLAB。
2. 在 Windows 文件资源管理器中打开本文件夹。
3. 双击 `RUN_THIS_FIGURE.m`，文件会在 MATLAB 编辑器中打开。
4. 点击 MATLAB 编辑器上方绿色三角形 **运行**。
5. 等待命令窗口出现“Fig. 10 已生成”。
6. 打开本文件夹中的 `输出`：
   - `输出/PDF/fig10_stability_domain.pdf` 是论文用矢量图；
   - `输出/PNG/fig10_stability_domain.png` 是600 dpi预览图；
   - `输出/plotted_data.mat` 保存真正送进 `plot` 的386个点；
   - `输出/data_audit.csv` 汇总六条曲线的点数和首末端点。

不需要把本文件夹设成 MATLAB 当前文件夹，也不需要手工添加搜索路径。

## 第二步：检查图是不是按原数据画的

1. 双击 `VERIFY_THIS_FIGURE.m`。
2. 点击绿色三角形 **运行**。
3. 命令窗口显示“Fig. 10 独立验收通过”后，打开 `输出/validation_report.txt`。
4. 报告第一行应为：

   ```text
   STATUS=PASS
   ```

5. 同一报告还应显示：
   - `CHECKED_CURVES=6`
   - `TOTAL_POINTS=386`
   - `MAX_POINT_ERROR` 不大于 `1e-12`
   - `CALCULATION_REPRODUCTION=NOT_PASSED`

## 也可以从MATLAB命令窗口运行

先用“主页 → 打开”找到脚本，然后使用编辑器的“运行”按钮最简单。如果想从命令窗口运行，可以把脚本完整文件名交给 `run`：

```matlab
run('你复制后的文件夹\RUN_THIS_FIGURE.m')
run('你复制后的文件夹\VERIFY_THIS_FIGURE.m')
```

上面的“你复制后的文件夹”只是操作示例，应替换为你电脑上实际位置。

## MATLAB到底做了什么

每一行CSV都记录一个延迟采样步。MATLAB按CSV原来的行顺序读取数据，并用下式换成毫秒：

```text
延迟毫秒 = (采样步 - 1) × 1000 / 1024
```

随后，MATLAB使用普通 `plot` 依次连接各点。它不会：

- 对点重新排序；
- 使用阶梯线；
- 人工增加 `(0,0)`；
- 从其他项目目录读取数据。

因此坐标轴从0开始，但真实曲线的第一个纵坐标是 `0.9765625 ms`，不是人为添加的0。

## “复现通过”具体指什么

这里通过的是**绘图级论文矢量逐点复现**：六条边界从梁禹硕士论文PDF中的矢量路径提取，MATLAB保持其386个点及顺序并重新绘制。

这里没有通过**计算级复现**：当前文件夹没有重新建立闭环特征方程或谱半径网格，也没有证明能够从物理参数重新算出这些边界。详细界限见 `来源与证据边界.md`。

## 常见问题

### 图没有从真实数据点0开始，是不是错了？

不是。坐标轴范围从0开始；真实数据使用1024 Hz采样，采样步2对应 `0.9765625 ms`。代码没有伪造原点。

### 为什么只出现少量标记？

全部386个点都由折线连接。为了避免标记互相遮挡，只在每条曲线上均匀显示最多9个标记；这不会删点，也不会改变曲线。

### 怎样确认自己没有画到旧数据？

运行 `VERIFY_THIS_FIGURE.m`，并核对 `validation_report.txt` 第一行是 `STATUS=PASS`。还可以用 `输入文件SHA256.txt` 核对六份CSV。
