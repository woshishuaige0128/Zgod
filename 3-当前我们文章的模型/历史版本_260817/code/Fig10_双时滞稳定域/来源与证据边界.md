# Fig. 10 来源与证据边界

## 当前成果

本文件夹生成小论文 Fig. 10，其中：

- 面板(a)对应梁禹硕士论文图4-4；
- 面板(b)对应梁禹硕士论文图4-5；
- Original、Craig-Bampton、Guyan共六条边界；
- 六份CSV合计386个有序点。

## 数据来源

六份CSV来自梁禹硕士论文PDF中图4-4和图4-5的矢量绘图路径。输入文件只保留这六条论文边界；没有混入旧的 `results_v2` 两边界候选数据。

CSV中的 `pdf_x_pt`、`pdf_y_pt`、`pdf_page_physical` 和 `pdf_drawing_index` 保存论文PDF矢量对象的追踪信息。真正用于小论文坐标轴的是 `tau1_step` 与 `tau2_step`，换算关系为：

```text
tau_ms = (tau_step - 1) × 1000 / 1024
```

## 已经通过的层级

**绘图级论文矢量逐点复现：通过。**

可核查证据包括：

- `point_order` 从1开始连续，严格保持CSV文件行顺序；
- 六条曲线点数分别为72、69、67、69、56、53；
- 总点数为386；
- `plotted_data.mat` 与六份CSV逐点误差不大于 `1e-12`；
- 使用普通有序折线，没有排序、阶梯线或人工原点；
- `validation_report.txt` 记录独立验收结果。

## 尚未通过的层级

**计算级复现：未通过。**

本文件夹不能证明梁禹如何从结构矩阵、子结构缩减、控制器和双时滞闭环方程重新计算出这六条稳定边界。它只准确重画论文中已经存在的矢量边界。因此，图形一致不能替代模型和算法的计算闭环。

## 使用结论

这套文件可以用于：

- 稳定重建小论文 Fig. 10；
- 审计实际绘制的每一个点；
- 检查坐标换算、点顺序、端点和输出文件。

它不能用于宣称：

- 梁禹原始稳定性求解代码已经找到；
- 双时滞稳定边界已经从物理模型重新计算；
- 论文中的稳定域在公式层面已经验证正确。
