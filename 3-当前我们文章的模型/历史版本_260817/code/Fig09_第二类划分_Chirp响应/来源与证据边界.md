# 来源与证据边界

## 输入

- 文件：`输入数据/第二类划分_Chirp响应.csv`
- 尺寸：40961行、10列。
- 时间：0–40 s，步长1/1024 s。
- 各层三列的原始顺序：Original、Guyan、Craig–Bampton。

## 本文件夹能够证明的内容

本文件夹从自带CSV逐点读取响应，重建一层和三层的全时程及两个局部放大窗。MATLAB保存的数据快照必须与CSV逐点一致，验收阈值为最大绝对误差不超过 `1e-12`。

## 本文件夹不能证明的内容

CSV是已经形成的历史响应数据。本文件夹没有重新运行结构动力学模型、数值积分器或实时混合试验，因此这是**数据驱动的绘图级复现**，不是从质量矩阵、刚度矩阵和时滞模型开始的**计算级复现**。
