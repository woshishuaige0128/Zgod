| --- | --- |

| `panels/子图素材清单.csv` | 独立素材与图号、楼层、时间窗的对应关系 |

图内已移除所有(a)(b)等子图编号及其后的说明，包括Division、Mode、El Centro、Chirp和标题中的NRMSE；这些信息已移入caption。图2的框架/截面标题、图4的子结构名称及颜色说明也已移入caption。坐标轴、单位、节点/尺寸、公式、曲线图例及图6的12项频率保留。

完整图的编号按正文出现顺序确定，与历史源PDF文件名前缀不完全相同。组图时请以本文件夹的fig1至fig15为准。

图7、8、10、11的独立素材按首层全时程、首层两个局部窗、顶层全时程、顶层两个局部窗依次命名a至f。您可分别标六个字母，也可仅对两整行标(a)(b)；`captions.md`中提供两种写法。图1和图3各为单图，独立目录中虽用fig1a、fig3a命名，组图时无需加(a)。

SVG/PDF均为矢量。SVG文字已转为轮廓，缩放不会失真；前四图的文字及线条在PPT/PPTX中可以单独编辑。全部15图的caption均写在相应幻灯片备注中。

图1、图3和图4的65组公式与变量已合并文本框；上下标采用原生文字格式，可进入同一文本框直接修改。前四页仍可逐个编辑线条和文字。第5至15页以EMF矢量图整体插入，可等比缩放和移动；各独立子图仍位于`panels/`。制作前的磁盘文件和当时未保存的打开状态保存在`source/all15_ppt_update_20260907/`。

正文、正文当前引用的图片和数值数据保持原样。本次处理为图件整理与标题迁移。
