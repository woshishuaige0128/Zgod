## 1. 为什么上一版是8张、这里是10张

- 用户最初指定的 `manuscript_0823.tex` 含8个 `figure` 环境，因此上一轮严格按该文件制作了8组图。
- 同目录更新较晚的 `manuscript_0823V2.tex` 含10个 `figure` 环境，和本次用户确认的“十张图”一致。
- 两个新增图位不是新增算例，而是把原8图稿中的两张四行响应总图拆成四张：El Centro第一类/第二类各一张，Chirp第一类/第二类各一张。
- 本次没有修改 `manuscript_0823.tex`、`manuscript_0823V2.tex`、现有正式图片或已编译PDF。

1. RTHS闭环图；

7. 第二类El Centro响应；

## 4. 生成方式与状态边界

- 使用方式：Codex内置 `imagegen`，以大论文裁图作为图像参考；没有切换到普通Matplotlib重绘，也没有使用CLI/API回退。
- 统一视觉约束：白色背景、Computer Modern风格衬线字体、深灰结构线、Tol蓝 `#4477AA`、Tol红 `#EE6677`、无阴影/渐变/3D/水印。
- 当前文件是Image 2栅格预览，不是最终投稿矢量PDF，也尚未插入TeX。
- `生成预览/` 保留首版和修正版，便于追踪Image 2出现过的编号/方向错误；`最终候选/` 只放当前推荐版本。
- 用户确认图1至图5的视觉风格后，再决定是否替换现有正式图、怎样组合图4/图5，以及是否按 `manuscript_0823V2.tex` 建立十图版新TeX副本。
