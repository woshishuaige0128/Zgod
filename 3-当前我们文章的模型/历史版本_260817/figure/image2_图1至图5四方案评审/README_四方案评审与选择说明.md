## 3. 选择时需要注意

- 图4和图5必须按同一个字母整套选择，不能把不同方案的(a)/(b)随意混搭。
- 图5方案D是概念化覆盖图，省略节点号和转角自由度；它适合解释“物理范围+两执行通道+中间层重构”，逐节点坐标仍由紧随其后的表格承担。若选择D，正式稿图注应补充“conceptual view”。
- Image 2候选适合确定信息架构和视觉方向。最终投稿图仍建议依据所选方案重新建立参数化矢量源码，保证数学字体、标签位置和PDF矢量性可控。
