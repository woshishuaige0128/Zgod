# `manuscript_0823` 期刊图片包

## 一句话说明

本目录包含 `manuscript_0823_with_figures.tex` 使用的八组正式图片、每组独立源码、输入数据快照和验证记录。图片来自梁禹大论文既有复现证据链；本任务只做期刊规范重绘与多面板重排，不新增算例、不重新运行 Simulink，也不把新建重绘代码称为梁禹原始源码。

## 目录用途

- `PDF/`：LaTeX 实际引用的单页矢量图。
- `PNG/`：同图600 dpi审阅版；`全部期刊图缩略图总览.png`仅用于快速总览。
- `源码/`：八个独立入口、一个共享绘图核心、统一样式、一键生成和验收脚本。
- `输入数据/`：从既有28图复现包逐字节复制的参数、响应和稳定边界快照。
- `验证记录/`：图片质量、数据来源哈希、编译和视觉检查记录。
- `图片对照索引.csv`：可筛选的逐图对照表。

## 统一出图规范

- Computer Modern，9 pt。
- 原结构：深灰 `#333333`、实线、圆标记。
- Craig–Bampton：蓝色 `#4477AA`、虚线、方形标记。
- Guyan：红色 `#EE6677`、点划线、三角标记。
- 坐标轴0.8 pt，曲线1.2 pt（长时程0.75 pt），刻度向内且四边显示。
- 无图内标题、无网格、图例无边框。
- 每组同时导出单页矢量PDF和600 dpi PNG。

## 如何重新生成

在 `figure/源码` 中执行：

```powershell
$env:PYTHONIOENCODING = "utf-8"
& "D:\Software\python\python.exe" ".\生成全部期刊图片.py"
& "D:\Software\python\python.exe" ".\验证全部期刊图片.py"
```

如果只想重画某一组，直接运行编号为01至08的对应脚本。每个独立入口文件开头均写明应对照的大论文图号与PDF页。

## TeX引用方式

新稿在导言区使用：

```tex
\graphicspath{{figure/PDF/}}
```

正文按下列形式引用：

```tex
\includegraphics[width=0.98\textwidth]{fig_eq_response}
```

原始 `manuscript_0823.tex` 不引用本目录，也不会被修改；插图只发生在新建的 `manuscript_0823_with_figures.tex` 中。
