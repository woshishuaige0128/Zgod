## 为什么旧版图4-4的 Guyan 不接近横轴

当前 `results_v2` 的旧版数据把图4-4 Guyan 画到网格 `(52,10)`，对应约 `(49.8047, 8.7891) ms`。论文矢量路径的最右竖边是 `(58,2)` 与 `(58,3)`，对应 `tau1=55.6641 ms`、`tau2=0.9766/1.9531 ms`。

旧代码还会先按横坐标排序，再使用 `drawstyle="steps-post"`；这个处理适用于每列只保留一个上边界点的旧 CSV，却会破坏论文矢量路径中的竖直段。新生成器严格保留 `point_order`，使用普通有序折线，并按

`tau_ms=(tau_step-1)*1000/1024`

换算为毫秒。

## 代码身份

- `MRren` 是作者 Guyan 历史单侧缩聚质量矩阵：

  `MRren = Mmn - Mmsn*(Ksn\Ksmn)`

  它不是 Craig--Bampton 的 `MRcb`。
- Craig--Bampton 候选脚本中的 `MRren` 是复制残留；清除残留可使代码身份更干净，但不能得到论文图4-4/4-5。
- `lqr_2.mat/lqr_3.mat` 没有找到现存的完整生成器。它们在本包中只能标为“作者历史绘图数据”。
- `huitu_2.m` 只消费工作区中的 `stab_o/stab_C/stab_g` 并提取边界，不负责生成三组谱半径网格。
