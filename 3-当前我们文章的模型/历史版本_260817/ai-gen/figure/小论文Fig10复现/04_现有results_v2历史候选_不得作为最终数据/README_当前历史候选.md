# 当前 results_v2 Fig. 10 的身份

当前旧版图的期刊版式、矢量 PDF 和600 dpi PNG质量合格，但其数据不是硕士论文的完整矢量路径。

旧数据来自作者 `lqr_2.mat/lqr_3.mat` 的上包络，每个横坐标只保留一个最高点；绘图核心随后按横坐标排序，并使用 `drawstyle="steps-post"`。这种路线会丢失论文路径右侧的低点和竖直段。

最明显的差异是图4-4 Guyan：

- 当前旧版：网格右端 `(52,10)`，约 `(49.8047,8.7891) ms`；
- 论文目标：网格右端 `(58,2)/(58,3)`，约 `(55.6641,0.9766/1.9531) ms`。

`新旧数据差异说明.csv` 由独立验收脚本自动生成，逐方法列出点数、交集、旧版独有点、旧版缺失的论文点和两端坐标。
