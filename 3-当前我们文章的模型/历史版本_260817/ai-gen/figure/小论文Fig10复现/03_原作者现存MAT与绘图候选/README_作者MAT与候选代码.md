# 作者 MAT 与候选代码的使用边界

- `huitu_2.m` 假定工作区已存在 `stab_o`、`stab_C`、`stab_g`，随后组合、提边界并画图。它不生成三组稳定性矩阵。
- `lqr_2.mat` 和 `lqr_3.mat` 是当前可找到的作者历史绘图数据；没有找到保存这两个文件的完整生成代码。
- `历史稳定域候选代码/` 收录当前可找到的14个 `.m` 转存候选。文件名不能证明方法身份，必须看矩阵和计算内容。
- `phy_MRren来源.m` 第54行给出 `MRren` 的历史 Guyan 单侧定义。
- `luxvjie_cb_LQR2.m` 与 `luxvjie_cb_LQR3.m` 存在 Guyan 的 `MRren` 复制残留，并且没有形成论文所需的完整 LQR 双时滞扫描。

这些文件用于追溯“作者当时可能怎样组织代码”，不能作为本包最终 Fig. 10 的数据生成器。
