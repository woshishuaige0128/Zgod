# 梁禹大论文图1—图5原图留档

## 留档目的

本目录保存期刊稿图1—图5所对应的梁禹大论文原图依据。图4和图5各含两个面板，因此共保留7幅图。所有图片均来自 `梁禹手稿.pdf`，没有使用 Image 2 生成内容，也没有重绘、修字或改动图内标注。

完整 PDF 是最高保真原始证据。对第21、28、29、30、37和59页执行 `pdfimages -list` 均未发现独立嵌入位图，所选原图属于 PDF 页面矢量内容。`02_高分辨率使用版_仅裁边` 中的 PNG 是从完整 PDF 页面在 600 dpi 下渲染后仅裁边得到的方便使用版本；它们是栅格派生文件，不替代完整 PDF 中的矢量原图。

## 目录说明

- `00_完整源PDF/梁禹手稿.pdf`：83页完整源论文副本，保留全部矢量页面内容。
- `01_原始裁图_字节保真/`：此前从论文 PDF 直接获得的7张约180 dpi裁图；与来源目录中的同名文件逐字节一致。
- `02_高分辨率使用版_仅裁边/`：7张600 dpi使用版；只裁除页面白边，以及图1和图5(a)下方误带入的相邻正文/下一图局部。
- `图片来源与哈希.csv`：每个面板的图号、页码、文件名、像素尺寸和 SHA-256。
- `03_验证记录/裁剪坐标与像素匹配.csv`：180 dpi来源定位与600 dpi使用版的精确裁剪框。
- `03_验证记录/extract_original_figures_600dpi.py`：7张使用版的可重复提取脚本。
- `03_验证记录/build_archive_contact_sheet.py`：总览图生成脚本。
- `03_验证记录/图1至图5原图总览.png`：7幅原图的快速目视核对页。
- `03_验证记录/原图留档验收.md`：哈希、像素和目视验收结论。
- `03_验证记录/归档文件清单.csv`：除清单自身外，归档包内全部文件的字节数与 SHA-256。

## 使用建议

1. 科学内容检查时，先打开完整源 PDF，并按上表页码核对大论文原图及其上下文。
2. 论文排版时，可使用 `02_高分辨率使用版_仅裁边` 中的 PNG；不得把这些文件描述成重新计算或重新绘制的结果。
3. 若需重新提取，在 PowerShell 中运行：

   ```powershell
   $env:PYTHONIOENCODING = "utf-8"
   & "D:\Software\python\python.exe" ".\03_验证记录\extract_original_figures_600dpi.py" --output-dir ".\重跑检查" --verify
   ```

4. 这套留档只证明图片来源与像素复现关系，不证明梁禹大论文中的画法或科学结论必然正确。后续采用、修正或重绘时，应结合期刊稿正文和模型定义另行判断。

## 本轮边界

本轮没有把这些原图插入 TeX，也没有替换已生成的 Image 2 候选图。用户确认采用哪一套表达后，再从受保护稿件复制新 TeX 并插图。
