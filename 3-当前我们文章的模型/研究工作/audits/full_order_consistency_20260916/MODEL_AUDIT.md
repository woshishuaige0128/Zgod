# 模型一致性核查：代数说明

## 1. 两种不同的完整空间

无时滞精度链直接在原框架15个自由度上构造基底。标准Guyan采用TᵀMT、TᵀCT、TᵀKT；CB添加质量归一化内部模态。内部模态取零时等于Guyan，取全时基底可逆，恢复原矩阵、荷载及输出。两种划分均实际通过检查。

局部装配的物理/数值坐标来自原稿表：划分一为6/14，交集5个，只共享2个后为18；划分二为9/12，交集6个，只共享2个后为19。额外独立坐标来自未协调的重复界面变量，并非原框架精细化。

以G表示遗漏界面的位移差算子，J表示从完整15坐标复制到两侧局部坐标的映射。实际检查GJ=0、rank(J)=15、rank(G)=3或4，以及JᵀA_UJ=A_F（A=M,C,K）及荷载映射。完整协调同时通过变分装配传递对应界面力。只在两作动坐标合并时，缺失的界面传力条件不能由局部求解自行补足。

划分一在沿用源MPrt的集中质量分配并令M_N=M_F−M_P时，数值侧ψ7质量为零。未协调18坐标系统质量秩17，数值侧固定界面广义特征值有一个无穷值。完整内部坐标基底依然可逆，故18坐标的装配恒等式成立；这不等于普通正定质量的全有限CB模态展开已成立。Rayleigh刚度比例阻尼还使该零惯性方向可能含一阶动态，不能未经推导直接删去或加小质量。

## 2. 有时滞的坐标变换核查

记x=Wq，W是划分二全内部模态的可逆变换。令E_x、E_q分别选取自然坐标与变换后坐标的两个作动分量。相等n步时滞定义D_x(z)=I+(z^(−n)−1)E_x，D_q(z)=I+(z^(−n)−1)E_q。

原物理列延迟再投影给出WᵀK_P D_x W；当前模型先投影再按广义坐标列延迟给出WᵀK_P W D_q，阻尼同理。零时滞时两式相同，非零时滞时一般不同。若将自然坐标定义的延迟原样变换到全内部模态空间，应使用W^(-1) D_x W，通常不能继续沿用原先的对角选列形式。

本轮在n=4、z=exp(i 2π9/1024)核验，刚度和阻尼两式的相对矩阵差分别约0.015635、0.029638。Python与MATLAB独立计算相符。这是算子恒等式反例，不是新增扫频计算，也不是响应误差大小。

现稿“延迟保留坐标＋当前内部模态”的恢复关系可被解释为其自身的虚拟RTHS反馈约定。本轮不将该约定本身判作程序错误；判断是：它不能仅凭全模态基底可逆，就被认定为原物理坐标纯列时滞模型的等价变换。

因此，当前19模型可作为该恢复约定下的全内部模态参照，衡量内部截断偏差。它与当前Full15参照的差，在非零时滞下同时含接口协调和延迟恢复路径差异。需要修正前轮将其统称为接口协调误差的解释。

## 3. 响应差值与指标

既有数据给出严格恒等式：

yr(τ)−y原 = [yr(τ)−yU(τ)] + [yU(τ)−yF(τ)] + [yF(τ)−yF(0)] + [yF(0)−y原]。

这里y原为原无控制RK4完整框架；yF为当前CR、共同LQR完整框架参照；yU为当前全内部模态19参照；yr为Guyan或CB物理端恢复输出。四项依次为当前路径下的缩聚偏差、参照模型差异、同一完整闭环的时滞影响、控制与积分设置变化的合并影响。

每一项的NRMSE不能直接相加。平方误差总量还含两两交叉项；本轮对这两种恒等式均逐条检验。没有新增控制开关或积分器对照，因此第四项不再分解为各自独立贡献。

## 4. 科学结论与后续建议

本轮有充分证据说明旧两套路线尚未构成同一完整框架等时滞闭环的阶次近似。改变输入频段不能修复这项定义差异。

建议评估“先固定完整框架的物理反馈路径，再一致投影全部当前项、延迟项、控制、荷载和输出”的统一虚拟数值路线。全空间恢复原定义闭环应成为后续必检极限；这项路线是否符合两实际作动器的接口实现仍须单独论证。

本轮不修改eq:assembled-reduced、eq:delay-recovery、eq:delayed-eom、eq:z-matrix，也不重新选择局部质量或激励。报告中的修订范围是供下一轮讨论的建议。
