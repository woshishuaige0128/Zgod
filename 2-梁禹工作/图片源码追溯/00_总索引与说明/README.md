# 梁禹硕士论文图片源码与重绘包

本目录是 Doctor Bego 最终统一审阅的入口。项目目标不是简单从 PDF 截图，而是为论文中的 28 个实际图片实例建立“原始来源—输入数据—可复现代码—PDF/PNG结果—验证记录”的证据链。

## 图片范围

| 章节 | 实际图片数 | 内容 |
|---|---:|---|
| 第1章 绪论 | 1 | 技术路线图 |
| 第2章 系统缩聚理论和模型建立 | 9 | 控制框图、缩聚/结构/自由度示意、Simulink模型 |
| 第3章 系统缩聚对RTHS试验精度的影响 | 13 | 自由度选取及单位、地震、Chirp响应 |
| 第4章 系统缩聚对RTHS试验稳定性的影响 | 5 | 控制/极点/结构示意及稳定域 |
| 第5章 结论与展望 | 0 | 原稿无图 |

合计 28 张，其中 13 张为 MATLAB 结果图，15 张为嵌入示意图、Simulink截图或外部文献素材。

## 重要真实性说明

- `原始源码`：确实能从梁禹 MATLAB/Simulink 工程追溯到的代码或模型。
- `原始嵌入素材`：从图书馆版 DOCX 或答辩 PPTX 恢复的 EMF/PNG 等；不等同于原生 PowerPoint、Visio 或绘图工程。
- `新建重绘代码`：原始可编辑工程缺失时，根据论文内容和嵌入素材建立的参数化矢量代码。此类代码不会被描述成梁禹原始代码。
- `外部引用图`：明确来自参考文献的内容，保留来源与引用属性，不宣称原创。

## 原稿已确认的问题

1. 第3章不存在图3-3和图3-4，是编号断档，不是整理遗漏。
2. 五张Chirp响应图按正文应为图3-11至图3-15，但原题注依次为“3-11、3-11、3-13、3-13、3-13”。本包同时保留原稿图号和整理唯一ID。
3. 图书馆版 DOCX 的最后一张Chirp响应图错误复用了地震激励局部窗。重建时以真实Chirp仿真数据为准，答辩PPT第20页正确局部图只作为视觉核验。
4. 原MATLAB绘图脚本依赖未显式加载的工作区变量，并硬编码原作者桌面路径；本包的新入口消除这些隐式依赖。

## 绘图规范

- 27张参数化重绘/曲线图使用 Computer Modern 9 pt；图2-9保留原生Simulink导出的嵌入 Arial/宋体作为可追溯例外，且禁止Type 3字体；
- 原结构深灰/黑色，Craig-Bampton `#4477AA`，Guyan `#EE6677`；
- 坐标轴四边显示、刻度向内；
- 无图内标题、默认无网格、图例无边框；
- 物理量与单位采用 `Quantity (unit)`；
- 每张图同时导出矢量 PDF 和 600 dpi PNG。

## 审阅顺序

1. `图片总索引.csv`：逐图进入来源、代码、数据、结果和验证记录。
2. `全部图片缩略图总览.pdf`：一次浏览28张最终图。
3. `验证总报告.md` 与 `图片完整性审计.md`：查看自动与人工验收结论。
4. 各章节目录：深入检查单图证据。
