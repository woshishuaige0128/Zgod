# 第4章“系统缩聚对RTHS试验稳定性的影响”图片交付

本目录包含手稿第4章的5张图片。图4-1至图4-3为依据原稿证据新建的矢量重绘；图4-4与图4-5的既有主图属于“作者现存MAT到边界”的绘图级复跑。论文PDF中的六条矢量边界已另行逐点复刻，但四个预声明动力学候选均未计算命中六条论文曲线，因此不能标为计算级复现。

## 一键生成

使用系统指定Python，可从任意当前目录执行：

```powershell
$env:PYTHONIOENCODING = "utf-8"
& "D:\Software\python\python.exe" "D:\JZ_PhD\10_论文_Papers\Li\RHTS\liangyustability-master\figure\第4章_缩聚对试验稳定性的影响\可复现代码\生成第4章全部图片.py"
```

该入口会重新计算来源SHA-256、从作者现存MAT恢复两类历史稳定域边界CSV/MAT，并真正调用5张图的绘制函数生成PDF和PNG；它不会重新求解闭环特征根。

## 关键文件

- `章节交付清单.csv`：每张图的代码、数据、PDF、PNG、来源、恢复方式和状态。
- `来源与恢复说明.md`：图4-1外部引用身份、图4-4/4-5稳定域证据链和数据异常处理。
- `输入数据/第4章稳定域统计.csv`：最大时滞、边界面积、稳定网格面积代理与源数组尺寸。
- `原始来源副本/SHA256清单.csv`：全部保存来源证据的哈希。
- `验证记录/`：逐图人工视觉与数值验证记录、PDF渲染预览和自动验收JSON。

## 诚实边界

现存MAT路线可以重复生成其自身边界，但不能代表论文六条曲线的完整忠实边界：两条Original路径与论文一致，四条Craig--Bampton/Guyan路径与论文冲突。完整的六模型链、四候选、49,848点双求解器计算及失败裁决位于`图4-4与图4-5_完整数值复现审计_未通过/`；详细证据见`来源与恢复说明.md`。
