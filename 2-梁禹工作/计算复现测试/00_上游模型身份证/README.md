# 上游模型身份证

这里记录所有下游图表共同依赖的6个上游计算门槛。板块15只建立父目录，不预先创建成功子目录。

- U01：参考结构参数与15自由度矩阵。
- U02：完整模型前五阶频率与质量参与系数。
- U03：第一类物理/数值子结构划分。
- U04：第二类物理/数值子结构划分。
- U05：Guyan历史单侧实现、论文公式与标准双侧合同投影。
- U06：Craig--Bampton三固定界面模态的实际实现。

每个身份证必须列出自由度顺序、矩阵维数、来源代码、输入哈希、公式、实际运行输出和独立复核结果。上游对象未闭合时，下游图表只能保持 `绘图级复现`、`历史值` 或 `待决定`。
