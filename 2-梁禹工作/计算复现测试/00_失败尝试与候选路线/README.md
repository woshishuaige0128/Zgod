# 失败尝试与候选路线

本目录保存真实运行但未达到预设验收门槛的尝试。板块目录用于保存某一阶段的中央冻结输入、代码和完整输出；对象目录用于交付可单独阅读的失败证据包，两者不能混作正式成功目录。

每次失败尝试至少保存：

- 对象ID、论文图/表/结论名称和尝试时间；
- 输入文件来源与SHA-256；
- 实际运行命令、退出码和完整日志；
- 使用的公式、参数、自由度顺序和输出位置；
- 论文目标值、绘图数据基准、实际值和误差；
- 失败原因与下一条候选路线。

失败是证据，不得删除、覆盖或移入成功目录。参数或公式改变时必须新建一次尝试记录。
