# 梁禹硕士论文完整计算线路复现区

本目录只用于复现《梁禹手稿.pdf》中报告的计算线路。保护源包括硕士论文、梁禹原工程、既有绘图数据和 `manuscript_0824.tex`；这些文件只读，不在本目录外改写结果。

## 当前阶段

板块15只建立隔离基线，不代表任何新计算已经成功。当前只允许存在三个 `00_...` 基础目录：

- `00_总索引与复现规则`：45项对象总索引、源文件冻结清单、运行环境和验收记录。
- `00_失败尝试与候选路线`：后续未达到预设门槛的真实尝试、命令和日志。
- `00_上游模型身份证`：参考结构、自由度划分、缩聚矩阵等上游对象的身份说明。

## 成功目录规则

逐图、逐表或逐结论的成功目录只有在对应板块提前写明数值门槛、真实运行并通过独立复核后才创建。图片目录采用 `图号_图题`，例如 `图3-5_单位激励下的3层响应`。失败结果不得放入成功目录，也不得用手工常数冒充计算输出。

## 固定证据标签

- `计算级复现`：输入、源码、真实运行、原始输出和独立数值比对均存在。
- `绘图级复现`：可由冻结的MAT/CSV等结果数据重画，但尚未重建上游计算。
- `历史值`：只在论文、旧脚本或旧结果中出现，当前尚未独立算回。
- `待决定`：来源冲突、入口缺失或证据不足，不能判为成功。

总入口见 `00_总索引与复现规则/README.md`。
