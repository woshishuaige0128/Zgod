- 6个上游计算门槛；
- 28幅硕士论文图片，其中13幅是计算结果图、15幅是示意图/模型图；

`全部对象总索引.csv` 是唯一对象台账。现有证据不等于本目标已经重跑；应同时阅读 `当前证据等级` 和 `当前状态` 两列。

## 本目录文件

- `全部对象总索引.csv`：45项对象身份、页码、基准、证据等级和计划目录。
- `源文件冻结清单.csv`：保护源的绝对路径、大小、修改时间和SHA-256。
- `源文件冻结复核.csv`：独立脚本重新计算的哈希与逐项 `MATCH/MISMATCH`。
- `来源冻结摘要.md`：冻结范围和关键文件摘要。
- `运行环境.txt`：本板块使用的Python与可执行文件状态；本板块不运行MATLAB。
- `验收记录.md`：45项唯一性、冻结哈希、路径隔离和成功目录空置检查。
- `scripts/构建板块15基线.py`：从既有28图索引与固定对象定义生成基线。
- `scripts/验证板块15基线.py`：不依赖构建脚本的独立复核入口。

## 晋升为成功复现的门槛

1. 对象所属板块开始前，先在 `WORKFLOW.md` 写明输入、公式、真实运行命令、数值容差和预期结果。
2. 原始输入复制到 `test` 内的隔离工作区，复制件哈希必须与冻结源相同。
3. 真实运行产生原始MAT/CSV或等价数据；不得手工录入论文目标值作为计算输出。
4. 使用独立公式或独立脚本对结果复核，并与论文绘图数据逐项比较。
5. 全部门槛通过后才建立 `成功文件夹` 列所列目录；否则保存到 `失败尝试目录`。
6. 即使复现的是错误历史公式，也必须同时标明“历史实现”和与标准理论的冲突，不得把错误路线改名为标准路线。

## 板块15历史基线命令：禁止对当前演进台账运行

下列两条命令只用于从板块15冻结快照重建当时的历史基线。它们会覆盖当前已经演进的总索引或验收记录，**禁止直接对当前发布台账运行**。如需审计当前状态，应使用对应板块的冻结合同和独立验证器；板块20入口位于 `../00_失败尝试与候选路线/板块20_LQR时滞稳定域及图4-4至图4-5逐图计算复现/code/validate_board20_step7_final.py`。

历史命令仅作来源留痕：

```powershell
$env:PYTHONIOENCODING = "utf-8"
& 'D:\Software\python\python.exe' '.\test\00_总索引与复现规则\scripts\构建板块15基线.py'
& 'D:\Software\python\python.exe' '.\test\00_总索引与复现规则\scripts\验证板块15基线.py'
```

这两条命令的退出码只能裁决板块15历史基线，不能裁决板块16至板块20的当前对象状态。图4-4/图4-5当前证据应读取板块20的步骤8E、步骤8F和步骤8G独立验证结果。
