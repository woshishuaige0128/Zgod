## 成功目录规则

逐图、逐表或逐结论的成功目录只有在对应板块提前写明数值门槛、真实运行并通过独立复核后才创建。图片目录采用 `图号_图题`，例如 `图3-5_单位激励下的3层响应`。失败结果不得放入成功目录，也不得用手工常数冒充计算输出。

## 固定证据标签

- `计算级复现`：输入、源码、真实运行、原始输出和独立数值比对均存在。
- `绘图级复现`：可由冻结的MAT/CSV等结果数据重画，但尚未重建上游计算。
- `历史值`：只在论文、旧脚本或旧结果中出现，当前尚未独立算回。
- `待决定`：来源冲突、入口缺失或证据不足，不能判为成功。
